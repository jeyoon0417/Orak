# 📈 오르락내리락

가상의 주식·코인을 사고팔고, 번 돈으로 집·차·옷을 꾸미는 가벼운 픽셀 아트 웹 게임.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (단일 파일) |
| `manifest.webmanifest` | 홈 화면에 추가 (앱처럼 설치) |
| `sw.js` | 오프라인 캐시 |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `supabase-groups.sql` | 그룹 기능용 서버 테이블 (Supabase에서 한 번 실행) |

## 깃허브 페이지로 배포하기

1. 새 저장소를 만들고 (예: `orak`) 이 폴더의 파일을 모두 최상위에 올린다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 고른다.
3. 1~2분 뒤 `https://windul2.github.io/orak/`에서 열린다.
4. 도메인을 샀다면 같은 화면의 **Custom domain**에 입력하고, 도메인 업체 DNS에 깃허브 안내대로 레코드를 추가한다.

## 그룹 기능 켜기 (Supabase, 무료)

친구끼리 그룹을 만들고 초대 링크로 불러서 같은 시장에서 경쟁하는 기능이야. 모든 플레이어가 같은 시장을 보기 때문에 서버는 서로의 기록만 저장하면 돼.

1. https://supabase.com 에서 새 프로젝트를 만든다 (지역은 Seoul 추천).
2. **SQL Editor**에 `supabase-groups.sql` 내용을 전부 붙여넣고 Run.
3. **Authentication → Sign In / Providers**에서 **Anonymous sign-ins**를 켠다. (회원가입 없이 바로 그룹에 들어올 수 있게)
4. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사한다.
5. `index.html`에서 아래 두 줄을 찾아 값을 넣는다.
   ```js
   const SB_URL = window.ORAK_SB_URL || '';   // ← 'https://xxxx.supabase.co'
   const SB_KEY = window.ORAK_SB_KEY || '';   // ← anon public 키
   ```
6. 다시 배포하면 랭킹 탭 → 👥 그룹에서 만들기/참가가 열린다.

- 초대 링크 모양: `https://windul2.github.io/orak/#g-AB12CD`
- 그룹당 최대 50명, 기록은 30초마다 갱신
- anon 키는 공개돼도 되는 키야. 보안은 SQL의 보안 규칙(RLS)이 막아줘. 남의 기록은 못 고치고 같은 그룹 사람 기록만 볼 수 있어.
- 설정 전에는 그룹 탭에 "그룹 기능 준비 중"이라고만 나와.

## 새 버전 올릴 때

- `index.html`을 교체하고, `sw.js`의 `VERSION` 값을 올린다 (예: `orak-v1.0.1`). 그래야 기존 사용자 화면도 새 버전으로 바뀐다.
- 설정 화면 맨 아래 버전 표기(`v1.0.0`)도 같이 올린다.

## 테스트용 개발 도구

주소 끝에 `#dev`를 붙여 열면 (예: `.../orak/#dev`) 계좌 탭 아래에 시간 이동, 현금 추가, 경험치 추가, 초기화 버튼이 나온다. 일반 사용자에게는 보이지 않는다.

## 게임 규칙 요약

- 시작 자금 500만 원, 시즌은 매주 월요일 00:00(한국 시간)에 시작
- 현실 5초 = 1틱, 현실 10분 = 게임 하루
- 주식 상하한가 ±30%, 코인은 제한 없음
- 시즌이 끝나면 순위와 수익률에 따라 경험치 지급
- 산 물건·레벨·스킬은 시즌이 바뀌어도 유지

## 아직 남은 것

- **전체 온라인 랭킹**: 그룹 랭킹은 위 설정으로 바로 쓸 수 있다. 모르는 사람끼리 겨루는 전체 랭킹은 조작 방지를 위해 서버에서 가격을 만드는 구조가 필요하다.
- **광고**: 도메인 연결 후 애드센스 승인을 받고 `ads.txt`를 최상위에 올린다.
- **개인정보처리방침**: 구글 로그인·광고를 붙일 때 필요.

## 저장 방식

진행 상황은 브라우저 저장소(localStorage)에 저장된다. 같은 브라우저로 다시 들어오면 이어서 할 수 있지만, 브라우저 데이터를 지우거나 기기를 바꾸면 사라진다. 서버를 붙이면 구글 계정으로 이어하기가 된다.
